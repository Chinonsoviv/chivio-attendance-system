# Chivio Attendance System

A cloud-based attendance tracking system that automates record-keeping for organizations in real time.

![Status](https://img.shields.io/badge/Status-Live-brightgreen) ![AWS](https://img.shields.io/badge/Cloud-AWS%20DynamoDB-orange) ![React](https://img.shields.io/badge/Frontend-React.js-blue)

---

## Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** AWS DynamoDB (us-west-2)

---

## Features
- Mark attendance in real time
- Cloud storage with AWS DynamoDB
- Track Present, Absent, and Late statuses
- Live attendance rate and daily chart overview

---

## Setup
1. Clone the repo
2. Add your AWS credentials to `backend/.env`
3. Run `node server.js` in backend
4. Run `npm start` in frontend
5. Visit `http://localhost:3000`
